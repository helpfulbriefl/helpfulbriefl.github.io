# yumi_acess · personal page

Personal page of **@yumi_acess**, tester & developer. Cartoon paper style, a single `index.html`, no build step.

**Live:** https://helpfulbriefl.github.io/

- **Languages:** English (default), Русский, 中文. Direct links: `?lang=ru`, `?lang=zh`.
- **Texts:** all of them live in the `I18N` object near the end of `index.html` (`en`, `ru`, `zh`).
- **Interactive bits:** a magnifier that follows the cursor, a bug to catch (the counter is saved in the browser), a testing checklist and a copy-nickname button.
- **Fonts:** Balsamiq Sans, Pangolin and ZCOOL KuaiLe from Google Fonts.
- **Style references:** [PaperCSS](https://www.getpapercss.com/), [DoodleCSS](https://chr15m.github.io/DoodleCSS/), [Rough Notation](https://roughnotation.com/) and [NN/g on neobrutalism](https://www.nngroup.com/articles/neobrutalism/).

> 🇷🇺 Личная страница @yumi_acess. Все тексты лежат в объекте `I18N` в конце `index.html`. По умолчанию страница на английском, есть русский и китайский.
